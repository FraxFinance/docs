# Somnia

Somnia is supported in Frax Mesh as a standard EVM deployment in the Fraxtal hub model. It uses the same deterministic `0x000000...` OFT address set as Tempo, but it does not use Tempo's TIP-20 extensions or stablecoin-denominated gas flow. On Somnia, bridge fees are paid in native gas and routing uses the standard OFT and HopV2 contracts.

## Routing Model

- Fraxtal is the hub chain for Somnia.
- `Somnia -> Fraxtal` and `Fraxtal -> Somnia` are the direct routes.
- `Somnia -> other EVM chains` relays through Fraxtal with HopV2.
- Somnia uses standard OFT fee quoting and native gas. There is no Somnia-specific TIP-20 fee token path.
