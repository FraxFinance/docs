# $FRAX token

*FRAX Dashboard: https://frax.com/own-frax*

## Overview

**Frax** is the scarce commodity asset of the Fraxtal blockchain. It is the **native gas** token of the Fraxtal blockchain ([North Star hardfork](https://gov.frax.finance/t/fip-428-frax-north-star-proposal-v2/3652/17)). Validator staking in FRAX is planned for a future hardfork; today Fraxtal uses a sequencer operated by the Frax core team. FRAX total supply is permanently capped at 143M per [FIP-441](https://gov.frax.finance/t/fip-441-frax-1-token-1-mission-1-vision/3826). Thus, Frax is the only native monetary unit of the Fraxtal blockchain and Frax ecosystem.

Frax is not a governance token. It is a **Commodity Asset** used as base money on Fraxtal. It is issued natively on Fraxtal, an OP Stack rollup that settles to Ethereum. FRAX originated as FXS on Ethereum, which upgrades 1:1 to native FRAX through the Fraxtal bridge. Wrapped, bridged versions are available on other chains. While users and projects can build protocols that can use Frax as a staking and governance token, Frax itself is not a governance token. It is the sole asset of the Fraxtal blockchain.

Frax Finance’s DeFi stack uses Frax as a restakable asset that provides cryptoeconomic security and governance voting rights to manage certain parameters of various Frax Finance DeFi protocols (such as veFRAX). These contracts are built on top of the Frax asset and not the underlying utility of the Frax asset. This is similar to a project using restaked ETH as its governance rights token. The restaked ETH token provides voting rights, utility, and cryptoeconomic security to the protocol, but the underlying protocol does not have ETH minting rights nor control of the ETH asset. The protocol using restaked ETH cannot stabilize asset pegs or change the ETH supply as part of its protocol function. This is the same relationship between the Frax ($FRAX) asset and the DeFi protocols using Frax as cryptoeconomic security including Frax Finance’s DeFi protocols.

## FXS Upgrade to FRAX

Since April 28th, 2025, users can upgrade their token 1:1 from [FXS (ERC20)](https://etherscan.io/token/0x3432b6a60d23ca0dfca7761b7ab56459d9c964d0) to FRAX (Fraxtal native gas token) by bridging it to Fraxtal chain. Which can be done using this UI https://frax.com/upgrade-fxs

Users can wrap their native FRAX on Fraxtal to receive [WFRAX (an ERC20 representation)](https://fraxscan.com/token/0xfc00000000000000000000000000000000000002). WFRAX is compatible with Frax Mesh, allowing seamless transfers of WFRAX to other integrated chains in the Frax ecosystem.

## Commodity-like Properties

### Store of Value
Holding the asset is a store of value equal to all holders similar to BTC rather than being faced with dilution if not staked.

### Frax Burn Engine (FBE)
The Frax Burn Engine (FBE) uses frxETH fee revenue to buy back FRAX and burn it, starting with Q4 2026 revenue. Burns go through the Frax Burner contract on Fraxtal at [`0x7fdeE482A2FEaF08344e1049F0951Eb2c07Fd9a7`](https://fraxscan.com/address/0x7fdeE482A2FEaF08344e1049F0951Eb2c07Fd9a7).

### Supply Cap
FRAX total supply is permanently capped at 143,000,000 per [FIP-441](https://gov.frax.finance/t/fip-441-frax-1-token-1-mission-1-vision/3826). FIP-441 replaces the tail emission schedule from [FIP-428](https://gov.frax.finance/t/fip-428-frax-north-star-proposal-v2/3652/17) and eliminates the perpetual 3% tail emission that was planned after year six.

The remaining supply is released under annual budgets. Each budget is a spending cap, not a required emission. Unused amounts roll over and can be reassigned through governance.
