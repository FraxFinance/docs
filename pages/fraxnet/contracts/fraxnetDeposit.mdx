# FraxNetDeposit

## Overview

`FraxNetDeposit` is a cross-chain deposit and redemption contract used in the FraxNet ecosystem. It enables the minting of `frxUSD` from `USDC`, and its transfer to another chain using LayerZero’s OFT mechanism. It also supports redemption of `frxUSD` to `USDC` through the USDC custodian and the RWA redeemer, and sends the `USDC` to the target chain.

A branded deposit contract does the same for a [branded stablecoin](/fraxnet/branded-stablecoins): it mints the branded token instead of `frxUSD`, and redeems the branded token to `USDC`.

This contract serves as the implementation for [EIP-1967](https://eips.ethereum.org/EIPS/eip-1967) Beacon Proxies deployed from the `FraxNetDeposit` Factory contract. The current implementation is `FraxNetDepositV4`, version `4.0.0`.

## Key Features

- Deposits USDC to mint frxUSD
- Sends frxUSD cross-chain via LayerZero
- Redeems frxUSD back to USDC and sends it to the target chain
- Integrates with Circle’s CCTP V2
- Supports branded stablecoins
- Anyone can process deposits and redemptions, and the factory can pause both

## Initialization

```solidity
constructor(address _factory)
function initialize(uint32 _targetEid, bytes32 _targetAddress, bytes32 _targetUsdcAtaAddress) external
function initialize(address _targetAsset, uint32 _targetEid, bytes32 _targetAddress, bytes32 _targetUsdcAtaAddress) public
```

- Called once by the factory upon deployment. Other callers get `Forbidden`, and a second call reverts with `AlreadyInitialized`.
- Sets the target LayerZero endpoint ID, the target recipient address and, for Solana (`30168`), the recipient's USDC associated token account. It reverts with `AtaAccountNotInitialized` if the target is Solana and `_targetUsdcAtaAddress` is zero.
- The factory uses the 3-argument form for frxUSD deposit contracts and the 4-argument form for branded ones. The 4-argument form stores `_targetAsset` and reads its `custodian` and `router` from the factory's `brandFactory`. It reverts with `NoAllowedForSiloed` if the asset uses a siloed custodian.
- The constructor sets the immutable `factory` and marks the implementation itself as initialized.

| `CCTPNotConfiguredForThisChain()` | No CCTP V2 messenger or CCTP domain configured for target chain                                 |

## Functions

### Deposit Flow

```solidity
function processDeposit(uint256 amount) external payable returns (uint256 frxUSDOut)
```

- User must have previously sent USDC to their `FraxNetDeposit` contract. The contract does not pull USDC from the caller.
- Anyone can call it. It reverts with `Paused` while the factory is paused, with `SizeTooLarge` if `amount` is above 1,000,000 USDC, and with `InsufficientBalance` if the contract holds less than `amount` USDC.
- Deposits the USDC into the factory's `frxUSDCustodian` to mint `frxUSD`.
- Sends frxUSD to `targetAddress` via:

  - Direct transfer (if Ethereum)
  - LayerZero OFT through the factory's `remoteHop` (if other chains), with `msg.value` paying the fee from `quote`

- Branded deposit contracts mint the branded token instead, through its `BrandedCustodian` to `targetAddress` (if Ethereum) or through its `CrossChainRouter`, which bridges the frxUSD and mints on the target chain (if other chains).
- Refunds the contract's entire ETH balance to the caller.

### Redemption Flow

```solidity
function processRedemption(uint256 amount) external payable returns (uint256 usdcOut)
```

- User must have previously sent frxUSD, or the branded token, to their `FraxNetDeposit` contract.
- Anyone can call it. It reverts with `Paused` while the factory is paused, and with `InsufficientBalance` if the contract holds less than `amount` frxUSD.
- Branded deposit contracts first redeem `amount` of the branded token for frxUSD through its `BrandedCustodian`.
- Redeems `frxUSD` for `USDC` using:

  - The factory's `frxUSDCustodian`, up to the amount it can currently redeem
  - The factory's `rwaRedeemer` ([RWA Redemption Coordinator](/fraxnet/contracts/rwaRedemptionCoordinator)) for the remainder
  - It reverts with `SizeTooLarge` if the two together cannot cover `amount`

- Sends USDC to target:

  - Direct transfer to `targetAddress` (if Ethereum)
  - Stargate's USDC pool, `STARGATE_USDCE_POOL` (if Somnia, `30380`). `msg.value` pays the LayerZero fee, which the pool's `quoteSend` returns, and the pool refunds any excess to the caller.
  - Circle CCTP V2 (if other chains): `depositForBurn` through the factory's `cctpTokenMessengerV2`, to the CCTP domain in `eidToCCTPDomain`. It is a standard transfer (`maxFee` 0, `minFinalityThreshold` 2000) with no `destinationCaller`, so anyone can complete the mint on the target chain. The mint recipient is `targetAddress`, or `targetUsdcAtaAddress` if the target is Solana (`30168`). It reverts with `CCTPNotConfiguredForThisChain` if the messenger or the domain is not set, or with `AtaAccountNotInitialized` if the recipient is zero, and refunds the contract's entire ETH balance to the caller.

### Quoting

```solidity
function quote(uint256 amount) external view returns (IRemoteHop.MessagingFee memory)
```

- Returns the LayerZero fee for `processDeposit(amount)` in `nativeFee`. It previews the frxUSD minted from `amount` USDC and quotes the factory's `remoteHop` or, for branded deposit contracts, the branded `CrossChainRouter`.
- Deposits to Ethereum need no fee.

### Admin

```solidity
function recoverERC20(address tokenAddress, uint256 tokenAmount, address recipient) external
function setBrandedRouter(address _router) external
function setBrandedCustodian(address _custodian) external
```

- `recoverERC20` can only be called by the factory, which lets the factory owner recover ERC20 tokens.
- `setBrandedRouter` and `setBrandedCustodian` let the factory owner replace the branded `router` and `custodian` set at initialization.

### Utility Functions

```solidity
function asset() external view returns (address)
function version() external pure returns (uint256 major, uint256 minor, uint256 patch)
function scaleUpTo1e18(uint256 amount1e6) public pure returns (uint256)
function scaleDownTo1e6(uint256 amount1e18) public pure returns (uint256)
```

- `asset` returns the branded token for branded deposit contracts, and `frxUSD` otherwise.
- `version` returns `4.0.0`.
- Helper conversions between `1e6` and `1e18` decimal representations.

## Dependencies

- [`FraxNetDepositFactory`](/fraxnet/contracts/fraxnetDepositFactory)

- `IBrandedFactory`, `IBrandedCustodian`, `IRouter` for branded stablecoins

## Notes

- Factory is used for access control (e.g. pausing, recovering tokens) and holds the shared configuration: custodian, RemoteHop, RWA redeemer, CCTP V2 messenger and CCTP domains
- Redemptions use the USDC custodian's liquidity first and the RWA redeemer for the rest
- Emits an event for every processed deposit or redemption
- Calls that refund ETH send the contract's entire ETH balance to the caller, so only send ETH as `msg.value` on a call that pays a fee
